# 5. PRINCIPIO FUNDAMENTAL

La arquitectura debe seguir principalmente:

`OUTPUT = ORIGINAL + GENERATED`

La ruta ORIGINAL debe permanecer esencialmente intacta.

Arquitectura conceptual:

```text
INPUT
 |
 +-------------------- ORIGINAL -----------------------+
 |                                                     |
 +-> BASS ANALYSIS                                     |
     |                                                 |
     +-> detector de periodicidad / f0                 |
     |                                                 |
     +-> confidence                                    |
     |                                                 |
     +-> envelope                                      |
     |                                                 |
     +-> target f0/2                                   |
     |                                                 |
     +-> subharmonic synthesis                         |
     |                                                 |
     +-> HPF / LPF                                     |
     |                                                 |
     +-> GENERATED ------------------------------------+
                                                       |
                                                       v
                                                      MIX
                                                       |
                                                       v
                                                HEADROOM/LIMITER
                                                       |
                                                       v
                                                     OUTPUT
```

La ruta de análisis puede filtrar copias de la señal.

La ruta ORIGINAL NO debe pasar por todos esos filtros.

# 8. ESTABILIDAD DE F0

No aceptes cualquier estimación instantánea.

La frecuencia detectada debe tener:

- estabilidad temporal;
- hysteresis;
- smoothing;
- límites razonables de cambio;
- rechazo de outliers.

Ejemplo de algo NO deseado:

```text

94 Hz
53 Hz
109 Hz
64 Hz
```

en pocos milisegundos.

Debe seguir las notas del bajo de una forma musical.

Si cambia la nota:

70 -> 80 Hz

la estimación puede deslizarse/interpolarse durante un corto tiempo.

---

# 9. CONFIDENCE DE VERDAD

No quiero que `confidence` sea simplemente “hay bastante volumen”.

Quiero que combine información como:

- energía en banda grave;
- estabilidad del periodo;
- cantidad de ciclos válidos;
- correlación;
- relación señal/ruido;
- coherencia temporal;
- coherencia Mid;
- compatibilidad L/R;
- cambios razonables en f0.

Cuando confidence sea bajo:

`GENERATED -> 0`

de forma suave.

No genere subgrave simplemente porque algo esté fuerte.

- cantidad momentánea;

# 11. GENERACIÓN SUBARMÓNICA F/2

Lo importante es:

- continuidad de fase;
- cambios suaves de frecuencia;
- relación clara con f0.
